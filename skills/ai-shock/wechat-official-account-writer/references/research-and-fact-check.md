# Research And Fact Checking

Use this reference when the article depends on current information, factual claims, market data, product details, public policies, technical behavior, or external source material.

## Source Priority

Prefer primary and current sources:

1. Official pages, documentation, reports, filings, release notes, speeches, or announcement posts.
2. Direct repositories, product docs, issue trackers, changelogs, and standards documents.
3. Reputable media or specialist analysis with named authors and dates.
4. Community posts, personal blogs, forum threads, and social media as supporting signals only.

For recent news, compare publication dates and event dates. For product or software information, verify against official docs or repository state rather than relying on memory.

## Research Flow

1. Generate 3-5 focused queries from the topic, including official, explanation, comparison, and criticism angles.
2. Open and read the most relevant sources instead of relying on search snippets.
3. Extract only facts needed for the article: dates, names, numbers, feature behavior, quotes, and constraints.
4. Look for disagreement or missing context before making a strong claim.
5. Track source URLs for any claim that might be challenged.

## Claim Handling

- Use exact dates for time-sensitive claims.
- Use ranges or "据公开资料" when the source is not definitive.
- Avoid implying causation from correlation.
- Do not present community anecdotes as market-wide facts.
- Do not turn a source's opinion into a fact.
- When a number is old, say so or omit it.

## Attribution Style

For WeChat-friendly prose, attribution can be compact:

- `据官方文档，截至 2026 年 6 月 4 日，...`
- `GitHub 仓库显示，...`
- `多篇公开报道提到，...`
- `这更像是一个使用体验判断，而不是已经被验证的行业结论。`

Use plain text URLs when the user needs publish-ready material for the WeChat editor.

## Source Adaptation

When rewriting from source material:

- Do not mirror the source order unless that order is necessary.
- Combine multiple sources into a new outline.
- Change examples only when doing so does not change the facts.
- Keep short direct quotes rare and clearly attributed.
- Add your own analysis, implications, or operating advice so the article is not a summary collage.
