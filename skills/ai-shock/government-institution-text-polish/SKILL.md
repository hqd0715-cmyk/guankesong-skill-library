# 机构介绍的文本润色

## 适用场景

- 机构简介：政府机关、事业单位、参公单位、社会组织。
- 部门职能说明、政策背景陈述、公文类文本润色。
- 需要把 AI 生成的泛化表述改成体制内真实用语。

不适合普通文章、商业文案或个人写作的通用“去 AI 味”任务。

## 核心方法

| 原则 | 说明 |
| --- | --- |
| 替代而非删除 | 去掉 AI 痕迹的同时，用真实业务表达补回专业感。 |
| 用词精准 | 区分职能机构、办事机构、社会团体、民办非企业等概念。 |
| 关系清楚 | 明确谁主管、谁归口、谁承担职责，不省略隶属关系。 |
| 在地感 | 补足地域、部门、政策背景和当下工作重点。 |
| 时间感 | 避免百科式永久表述，写出当前阶段的工作语境。 |

## 工作流程

1. 判断文本类型：机构简介、职能说明、政策背景或社会组织介绍。
2. 识别 AI 痕迹：模糊用词、模板结构、空泛套话、缺少主管关系或在地信息。
3. 补足关键事实：机构性质、归口关系、核心职责、当前重点工作。
4. 重写为正式、克制、具体的中文表述。
5. 自查：概念是否准确、关系是否清楚、地点和时间语境是否成立。

## 触发线索

当用户提到以下内容时使用本技能：

- 机构简介、单位介绍、部门职能。
- 体制内文本、公文、政府网站风格。
- 把这段写成体制内风格。
- 去掉这段机构介绍的 AI 味道。

## Prompt 示例

```markdown
请按“机构介绍的文本润色”工作流改写下面这段文字：

输入：
东莞市精神文明建设办公室（简称市文明办）是东莞市精神文明建设委员会的办事机构，在市精神文明建设委员会领导下开展工作。
主要职责包括：统筹推进全市文明城市创建工作；组织开展社会主义核心价值观宣传教育活动……

输出要求：
1. 明确机构性质和归口关系。
2. 避免空泛套话，补足东莞本地工作语境。
3. 保持正式、克制、准确。
```
