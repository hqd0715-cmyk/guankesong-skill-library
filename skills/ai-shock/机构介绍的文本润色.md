# 机构介绍的文本润色

## 适用场景

- 机构简介（政府机关、事业单位、参公单位）
  - 部门职能说明
  - 政策背景陈述
  - 社会组织介绍（协会、学会、基金会）
  - 公文类文本润色
 
 ### ⚠️ 不适用场景

  这不是通用的"去AI味"工具。普通文章、商业文案、个人写作的去AI处理，请使用 [humanizer](https://claude.ai/code) 技能。

  ## 核心方法论

  | 原则 | 说明 |
  |------|------|
  | **替代而非删除** | 去掉AI痕迹的同时，用体制内真实用语注入专业感 |
  | **用词精准** | 职能机构 vs 办事机构，社会团体 vs 民办非企业——每个词都有特定含义 |
  | **关系清楚** | 谁管谁、谁归谁——隶属关系是核心信息，不能省略 |
  | **在地感** | 读得出来是东莞还是深圳，是教育部还是科技部 |
  | **时间感** | 不是永久有效的百科词条，而是有当下感的叙述 |

  ## 工作流程

  1. **判断文本类型** —— 机构简介 / 职能说明 / 政策背景 / 社会组织介绍
  2. **识别AI痕迹** —— 模糊用词、结构模板化、套话堆砌、缺少关键信息
  3. **按规则重写** —— 5条核心改写规则
  4. **自查检查** —— 7项检查清单确保质量

  ## 安装

  ### Claude Code

## 使用步骤

在 Claude Code 中，当你提到以下内容时会自动触发本技能：

  - "机构简介"、"单位介绍"、"部门职能"
  - "体制内文本"、"公文"
  - "把这段写成体制内风格"
  - "去掉这段话的AI味道"
  - "像政府网站那样写"

## Prompt 示例

```markdown
输入（AI原文）：

  ▎ 东莞市精神文明建设办公室（简称市文明办）是东莞市精神文明建设委员会的办事机构，在市精神文明建设委员会领导下开展工作。
  ▎ 主要职责包括：统筹推进全市文明城市创建工作；组织开展社会主义核心价值观宣传教育活动……

  输出（改写后）：

  ▎ 东莞市精神文明建设办公室，简称东莞市文明办，是东莞市统筹推进精神文明建设、文明城市创建和新时代文明实践工作的职能机构
  ▎ ，归口中共东莞市委宣传部。近年来，市文明办围绕全域文明建设、千万人口融合、"百千万工程"和城市品质提升，持续推进文明城
  ▎ 市常态长效建设……
```
